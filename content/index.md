# Dyscalculia Knowledge Repository

Welcome to the Ted Wragg Trust's comprehensive information repository for dyscalculia provision. This living knowledge base brings together policy research, legal frameworks, best practices, case studies, and implementation guidance to support effective provision for learners with dyscalculia across our Multi-Academy Trust.

</div>

<div class="home-overview">

## What You'll Find Here

This repository serves educators, SENCOs, leadership teams, parents, and governors with evidence-based information and practical tools for supporting learners with dyscalculia. Whether you're seeking statutory guidance, assessment procedures, intervention strategies, or real-world case studies, this platform provides accessible, up-to-date resources organized for easy discovery. This repository serves as both a working tool for daily practice and a strategic resource for long-term policy development.

## How to Use This Repository

- **Educators & SENCOs**: Access assessment procedures, intervention strategies, and classroom adaptations
- **Leadership Teams**: Generate policies, review compliance requirements, and track implementation
- **Parents & Carers**: Understand dyscalculia, learn how we identify and support learners, and access home resources
- **Governors**: Review statutory obligations, evidence-based practices, and Trust-wide provision standards
