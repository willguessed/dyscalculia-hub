## How do I access the repository?

The repository is accessible via web browser at: **[repository-url].tedwragg.org**

**Supported browsers:**
- Google Chrome (recommended)
- Microsoft Edge
- Mozilla Firefox
- Safari (macOS/iOS)

No login required for general access.


## Search isn't working or showing results

**Troubleshooting steps:**

1. **Check your search term**
   - Try alternative keywords (e.g., "math difficulties" vs "dyscalculia")
   - Use simpler terms
   - Check spelling

2. **Remove filters**
   - Active filters may be hiding results
   - Click "Clear Filters" if filters are applied

3. **Clear browser cache**
   - Press Ctrl+Shift+Delete (Windows) or Cmd+Shift+Delete (Mac)
   - Select "Cached images and files"
   - Reload the page

4. **Try a different browser**
   - Some older browsers may not support the search functionality

## The page isn't loading properly

**Quick fixes:**

1. **Refresh the page** - F5 or Ctrl+R (Cmd+R on Mac)
2. **Clear browser cache** - See above
3. **Check internet connection** - Ensure stable connectivity
4. **Disable browser extensions** - Ad blockers may interfere
5. **Try incognito/private mode** - Rules out extension conflicts

## Images or icons aren't displaying

This usually indicates a loading issue:

- **Refresh the page** - Images may not have loaded
- **Check internet speed** - Slow connection may timeout
- **Allow images in browser** - Ensure images aren't blocked in settings
- **Report persistent issues** - Email repository.admin@tedwraggtrust.org

## How do I print content?

**To print an article:**

1. Navigate to the content page
2. Press **Ctrl+P** (Windows) or **Cmd+P** (Mac)
3. Select your printer or "Save as PDF"
4. Adjust print settings (portrait/landscape, color)
5. Click "Print"

**Print-friendly features:**
- Optimized page breaks
- Readable fonts and sizing
- Headers/footers with page numbers

## Can I save content for offline use?

**Yes, several options:**

1. **Print to PDF** - Use browser print function, select "Save as PDF"
2. **Bookmark pages** - Browser bookmarks for quick access
3. **Browser save page** - Right-click → "Save page as"
4. **Copy/paste to document** - For personal notes

**Note:** Offline versions won't receive updates. Check online for latest content.

## The navigation menu won't open/close

The navigation panel is **collapsible**:

- Click **"Explore the Toolkit"** to expand
- Click **"Hide"** (or the arrow) to collapse
- State saves between pages

**If not working:**
- JavaScript must be enabled in your browser
- Clear cache and refresh
- Update to latest browser version

## Back button isn't appearing on content pages

The "Back to section" link appears **only if you navigated from a section page**.

If you:
- Arrived via search or direct link → No back button
- Bookmarked the page → No back button
- Cleared browser history → No back button

**Workaround:** Use browser back button or navigate via sections menu.

## Form submission isn't working

**Common issues and fixes:**

1. **Required fields missing**
   - Fields marked with * are mandatory
   - Check all required fields are completed
   - Look for red error messages

2. **Email format invalid**
   - Ensure email includes @ and domain (e.g., name@school.org)

3. **Browser JavaScript disabled**
   - Forms require JavaScript
   - Enable in browser settings

4. **Network timeout**
   - Submit button shows "Submitting..." indefinitely
   - Check internet connection
   - Try again after a few minutes

## I received an error message. What does it mean?

**Common error codes:**

- **404 Not Found** - Page doesn't exist; check URL spelling
- **500 Server Error** - Temporary server issue; try again later
- **403 Forbidden** - Access restricted; contact administrator
- **Loading errors** - Network or browser cache issue; clear cache

**For persistent errors:**
- Note the error code/message
- Screenshot the error if possible
- Email repository.admin@tedwraggtrust.org with details

## Can I use the repository on older computers?

**Minimum requirements:**

- **Browser**: Released within last 3 years
- **Operating System**: Windows 7+, macOS 10.12+
- **Internet**: Broadband connection
- **Screen**: 1024x768 resolution minimum

Older systems may experience:
- Slower loading times
- Layout issues
- Limited functionality

**Recommendation:** Use school computer lab or library resources if personal device is outdated.

## I'm experiencing slow loading times

**Optimization tips:**

1. **Close unnecessary browser tabs** - Free up memory
2. **Disable browser extensions temporarily** - Test impact
3. **Check internet speed** - Run speed test (minimum 5 Mbps recommended)
4. **Use wired connection** - Ethernet more stable than WiFi
5. **Peak usage times** - Repository may be slower during school hours

**If persistent:**
- Report to repository.admin@tedwraggtrust.org
- Include time of day and pages affected
